# Theme Guide

## Theme Name

LOGBOOK

## Design Direction

The project uses a dark editorial developer-journal style. The goal is to make the platform feel like a personal archive of articles, experiments, project notes, and technical insights rather than a generic blog dashboard.

## Color Palette

| Purpose | Color |
|---|---|
| Main Background | `#0b0f0e` |
| Header / Panel | `#111816` |
| Card Surface | `#16201d` |
| Border | `#26332f` |
| Accent | `#a3e635` |
| Accent Dark | `#84cc16` |
| Main Text | `#f4f7f5` |
| Muted Text | `#8a9a91` |

## UI Personality

- Dark editorial layout
- Developer journal aesthetic
- Lime accent color
- Minimal gradients
- Strong typography
- Clean blog cards
- Less SaaS-like, more personal and memorable

## Branding

Current brand name:

`LOGBOOK_`

The underscore gives the brand a terminal/developer feel.

## Component Style Rules

- Use dark backgrounds instead of white cards
- Use lime only for important actions, highlights, and hover states
- Use muted green-gray text for secondary information
- Avoid generic indigo/blue SaaS colors
- Avoid too many rounded pill elements
- Keep spacing generous and readable
