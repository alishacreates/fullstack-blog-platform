# Full Stack Blog Platform

A full-stack blogging platform with separate user and admin interfaces.

## Features

* User-facing blog platform
* Admin dashboard
* Create, edit, and delete blog posts
* Backend REST API
* Database integration
* Responsive design

## Tech Stack

### Frontend

* React
* Tailwind CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB
